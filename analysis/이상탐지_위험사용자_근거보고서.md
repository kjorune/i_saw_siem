# 이메일 유출 의심행위 및 이상탐지 위험 사용자 근거 보고서

## 1. 결론

2010-01-02~2011-05-17의 1,000개 계정, 330,452개 사용자×일 레코드에 Isolation Forest를 적용한 결과 상위 1%인 3,305개 사용자×일(598개 계정)이 모델 이상 후보로 분류됐다. 이 가운데 141개 사용자×일은 **모델 이상**과 **같은 날 파일 활동 급증 + 외부 첨부메일 + 대용량 또는 복수 첨부 규칙**이 동시에 관찰되어 우선 검토 가치가 높다.

이 결과는 실제 유출자나 공격자 판정이 아니다. 모델은 정답 라벨 없이 희귀한 행동 조합을 찾는 비지도 모델이고, 일 단위 규칙은 파일 이벤트와 메일 이벤트의 정확한 2시간 선후관계를 보장하지 않는다. 아래 대상은 원본 이벤트와 업무상 예외를 확인할 조사 후보이다.

## 2. 첨부 문서 내용 정리

### 분석 대상과 보수적 발신 판정

- 원본 이메일 1,314,400건 중 이벤트 월 LDAP의 `user_id`·`email`과 로그의 `user`·`from`이 모두 일치한 815,250건만 발신 추정 이벤트로 사용한다.
- 수신자의 도메인이 정확히 `dtaa.com`이면 내부, 그 밖의 유효 주소는 외부로 분류한다.
- 검증 이메일 중 외부 수신자 포함 이벤트는 136,519건(16.75%)이다.
- 외부 주소, 첨부, BCC, 시각, 크기는 관측 사실이지만 승인된 협력사 전송이나 정상 업무일 수 있다.

### 문서의 위험지표와 weak-label 정책

| 구분 | 정의 | 주요 임계값/해석 |
|---|---|---|
| 외부 전달 | `to/cc/bcc`에 외부 주소 존재 | 기본 탐색 신호이며 악성 확정 아님 |
| 외부 첨부 | 외부 수신자 존재 및 첨부 1개 이상 | 자료 전달 가능성, 내용·기밀성은 확인 불가 |
| 대용량 메일 | 사용자 과거 200건 p99 또는 median+6×보정 MAD 초과 | 개인 평소 대비 이상 |
| 비근무시간 | 주말 또는 평일 08시 이전·19시 이후 | 근무표 부재로 오탐 가능 |
| 신규 목적지 | 과거에 없던 외부 주소·도메인 | cold start 제외 필요 |
| 발송 급증 | 1시간 외부메일 5건 이상 | 초기 운영값 |
| 반복 전송 | 주간 외부메일 5건 이상 | 정기 보고 가능 |
| 장기 반복 | 선행 외부 활동 3주 이상·관찰 21일 이상 | NIA형 장기 반복 시나리오 |
| 복합 고위험 | 기본 외부 신호 외 3개 이상 동시 | 단일 신호 오탐 완화 |

첨부 보고서의 규칙 기반 결과는 S3 완성 후보 95 사용자×일·51개 계정이다. S3는 파일 활동 급증 후 외부 첨부메일이 이어지고 메일 크기 증가 또는 복수 첨부가 관측된 시간 순서 후보다. 문서 자체도 Isolation Forest는 실행하지 않았다고 명시하므로, 본 보고서에서 별도 모델을 실행했다.

### NIA 사례와의 연결

첨부 문서는 NIA 사례의 핵심을 장기간 반복적인 외부 이메일 자료 전달로 요약한다. 현재 로그에서는 실제 자료의 기밀성이나 전달 성공 여부를 확인할 수 없으므로 탐지 표현은 **“NIA 사건과 유사한 반복적 외부 이메일 자료반출 징후”**로 제한한다.

## 3. 이상탐지 모델

### 분석 단위와 입력 특징

- 분석 단위: 사용자×일
- 모델: Isolation Forest, 300 trees, `contamination=0.01`, `random_state=42`
- 절대량 특징: 외부메일, 외부첨부 메일, 첨부 수, 외부메일 크기 합계·최대, 외부 수신자·도메인·BCC, 비근무시간 외부메일, 파일·장치·로그온·HTTP 활동량
- 개인 편차 특징: 위 13개 특징 각각의 사용자 전체기간 median/IQR 기반 robust z-score
- 전처리: 절대량은 `log1p`, 전체 특징은 10~90 분위 범위 RobustScaler 적용
- 모델 점수: `-score_samples`를 전체 관측치 최소~최대 기준 0~100으로 변환

모델 상위 1%는 희귀성 기준이지 범죄 확률이 아니다. 개인 기준선에는 전체기간 통계를 사용했으므로 운영 환경의 시점별 미래 누출 없는 검증 모델과는 구분해야 한다.

## 6. 수치 해석

- 모델 이상 후보는 330,452개 사용자×일 중 3,305개(설정상 약 1.00%)다. 이는 데이터에서 상대적으로 희귀한 조합이라는 뜻이다.
- 일 단위 복합규칙 후보 352건 중 모델 이상과 겹친 건은 141건(40.1%)이다. 이 교집합은 단순 활동량 이상보다 외부 첨부·파일 급증이 함께 관찰된 우선 검토 집합이다.
- 첨부 문서의 정확한 2시간 S3는 95건·51계정이고, 본 재분석의 일 단위 복합규칙은 352건·65계정이다. 시간창이 넓기 때문에 본 규칙 후보 수가 더 많으며 두 수치를 동일하게 해석하면 안 된다.

## 7. 조사 절차

1. 외부 수신 도메인이 승인된 고객사·협력사인지 확인한다.
2. 제시한 메일 이벤트 ID로 실제 발송 방향과 전달 성공 여부를 확인한다.
3. 파일 이벤트 ID의 작업 유형, 파일명, 크기, 해시, 분류등급을 확인한다.
4. 파일 이벤트와 메일 첨부 해시가 같은지, 파일이 메일보다 먼저 발생했는지 확인한다.
5. 해당 시간의 로그인 세션, 근무표, 휴가, 관리자 승인 기록을 대조한다.
6. USB, 웹 업로드, 비정상 인증 신호가 같은 계정·PC에서 동반됐는지 확인한다.

## 9. 한계

- 정답 라벨이 없어 precision, recall, accuracy를 산출할 수 없다.
- 모델의 1% 임계값은 경보 처리 용량을 가정한 설정이며 최적값이 아니다.
- 개인 편차는 전체기간 분포를 사용해 과거 시점 모델 평가에는 미래 정보 누출 가능성이 있다.
- `size`의 단위와 첨부 포함 여부, 파일 활동 방향·해시·크기, 승인된 외부 목적지, 근무표가 없다.
- 콘텐츠 본문과 심리측정 정보는 모델에 사용하지 않았다.
- 관측된 시간적 선후관계도 인과관계나 실제 유출을 증명하지 않는다.
