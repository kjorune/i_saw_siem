# 이메일 기반 이상탐지 프로젝트 요약 회의록

- 일시: 2026.09.15
- 참석자: 이소이, 권순성, 김솔, 김현수, 강사님
- 회의 목표: 샘플 데이터 분석 결과를 바탕으로 프로젝트 주제와 기획안 방향 확정

## 1. 주요내용

팀원들은 샘플 데이터와 전일 회의 내용을 검토한 뒤 SIME 조기탐지 MVP 기획안, NIA 이메일 유출 사례, 사용자 행동 이상탐지 가기획안, 데이터 정의서와 이메일 분석 결과를 공유했다. 로그는 사용자·시간·PC를 중심으로 연결할 수 있으며, 데이터 형식과 사용자 컬럼을 통일한 뒤 이메일 행동을 사용자별 하루 단위로 분석하기로 했다.

샘플 데이터와 약 7일의 실질 개발기간을 고려해 외부 이메일 자료반출 이상징후 탐지를 핵심 주제로 선정했다. 파일 활동은 이메일 전 선행 정황으로 활용하고, 세부정보가 부족한 USB·로그온·웹 로그는 보조 또는 향후 확장 범위로 두기로 했다.

외부메일 수, 외부 수신자, 첨부파일, 메일 크기, 발송 시간, 신규 대상과 반복 행동을 개인의 과거 최대 30일 기준선과 비교한다. Z-score와 Robust Z-score를 우선 적용하고 Isolation Forest는 선택적 비교 모델로 검토하며, 실제 유출 확정이 아닌 위험 사용자 순위와 판단 근거를 제시한다.

공유된 분석에서는 발신자를 보수적으로 검증한 이메일 815,250건 중 외부 수신자가 포함된 이벤트 136,519건과 사용자×일 기록 289,783건을 분석 대상으로 제안했다. 파일 활동 급증 후 외부 첨부메일과 크기 증가 등이 이어진 후보 95건·51개 계정도 제시됐지만, 이는 정답 라벨이 아닌 우선 검토 후보로 해석하기로 했다.

강사님은 분석 근거는 적절하지만 기획서가 길고 항목 간 연결이 약하다고 피드백했다. 본문은 1~2장으로 줄여 주제·데이터 근거·위험지표·개발계획·결과물을 중심으로 구성하고, 상세 통계·코드·복잡한 점수식·부가 그래프는 부록으로 이동하기로 했다.

## 2. 오늘의 판단 기록

| 판단한 내용 | 판단 이유 |
|---|---|
| 이메일 외부 자료반출 징후를 메인 주제로 선정 | 실제 사례와 연결되고 샘플 이메일 로그로 필요한 행동지표를 계산할 수 있음 |
| 파일 활동은 이메일 전 선행 정황으로 사용 | 시간·사용자·PC를 이용해 이메일 발신 전 활동 증가를 연결할 수 있음 |
| USB는 보조 또는 확장 범위로 제한 | 연결·해제 외 장치 식별자와 전송량이 없어 독립적인 유출 판정이 어려움 |
| 사용자×일 및 과거 최대 30일 기준선을 적용 | 사용자별 업무량 차이와 반복 행동을 함께 보기 위함 |
| 결과는 실제 유출자가 아닌 조사 우선 후보로 표현 | 샘플 데이터에 실제 공격 정답 라벨이 없음 |
| Sigma Rule은 직접 실행보다 규칙 구조를 참고 | 현재 샘플이 Windows Event Log 형식이 아니어서 공개 Sigma 룰을 직접 적용하기 어려움 |
| 기획서는 1~2장으로 축약 | 분석 과정과 결론을 직관적으로 전달하라는 강사 피드백 반영 |

## 3. 다음 날로 넘기는 것

- 이메일 발생 월의 LDAP를 기준으로 발신자 검증 건수와 분석 모집단을 통일한다.
- 사용자 컬럼을 `user`로, 날짜를 ISO 8601 형식으로 통일한 정제 데이터를 공유한다.
- 위험지표 정의·임계값·설정 근거를 한 표로 정리하고 설명하기 어려운 용어는 제거한다.
- 정상·단일 이상·복합 이상 시나리오를 실제 Feature 변화가 보이도록 수정한다.
- 규칙 기반, Robust Z-score 및 선택적 Isolation Forest의 비교·검증 방법을 확정한다.
- 통합 기획서를 1~2장으로 축약하고 상세 데이터 정의서와 분석 결과는 부록으로 분리한다.
- 강사 피드백을 반영한 기획서와 관련 파일을 PDF로 변환해 다시 제출한다.
