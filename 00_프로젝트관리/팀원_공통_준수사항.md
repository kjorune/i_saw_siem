# 팀원 공통 준수사항

## 1. 소통

| 구분 | 도구 |
|---|---|
| 팀 내부 소통·파일 공유 | Slack |
| 멘토링·외부 연락 | 카카오톡 |
| 일정·과업·진행 현황 | Notion |

## 2. 파일 및 산출물 공유

- 팀원은 작성한 파일과 산출물을 Slack으로 공유한다.
- GitHub Push와 버전관리는 권순성이 담당한다.

## 3. 파일명

```text
[문서번호_]주제_내용[_YYYYMMDD][_vNN][_상태].확장자
예: 02_분석설계_20260921_v01_검토본.pdf
```

## 4. 일일 마감

- 업무 종료 전 당일 진행 상황과 산출물을 Notion에 작성한다.
