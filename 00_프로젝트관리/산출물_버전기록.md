# 산출물 버전 기록

공식 검토본, 현행본 또는 제출본을 생성할 때 아래 표에 한 행씩 추가한다.

| 문서명 | 버전 | 확정일 | 상태 | 작성자 | 검토자 | 변경 내용 | 관련 커밋·PR |
|---|---|---|---|---|---|---|---|
| 예: 위험분석보고서 | v01 | 2026-09-28 | 제출본 | 작성자명 | 검토자명 | 최초 제출 | `커밋 해시 또는 PR 링크` |

## 작성 기준

- 날짜는 `YYYY-MM-DD` 형식으로 작성한다.
- 상태는 `검토본`, `현행본`, `제출본` 중 하나를 사용한다.
- 변경 내용은 이전 버전과 달라진 핵심 사항을 한두 문장으로 작성한다.
- 관련 커밋·PR에는 해당 버전의 내용을 추적할 수 있는 Git 커밋 해시 또는 Pull Request 링크를 기록한다.
- 같은 문서의 새 버전을 만들면 기존 행을 수정하지 않고 새 행을 추가한다.
- 제출을 취소하거나 교체한 경우 기존 행을 삭제하지 않고 변경 내용에 사유를 기록한다.
