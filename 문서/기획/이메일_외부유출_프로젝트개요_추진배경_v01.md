# 1. 프로젝트 개요

## 프로젝트명

**SIEM 로그 기반 이메일 외부 유출 위험 사용자 탐지 및 위험 스코어링**

## 목표 및 범위

이메일 로그와 LDAP 정보를 활용하여 사용자별 평소 행동에서 벗어난 외부 전송을 탐지하고, 위험점수와 조사 우선순위를 제공하는 프로젝트이다.

| 구분 | 내용 |
|---|---|
| 목표 | 외부 전송 이상징후를 탐지하여 조사 대상의 우선순위를 제시하는 것이다. |
| 분석 데이터 | LDAP, device, email, file, http, logon, psychometric |
| 분석 단위 | 사용자별·일별 이메일 활동 |
| 분석 방법 | 사용자별 평소 행동을 기준선으로 설정하여 이상 정도를 산출하는 방식이다. |
| 결과물 | 위험 사용자 순위, 위험점수, 점수 산정 근거 |
| 해석 범위 | 실제 정보유출자를 확정하는 것이 아니라 조사가 필요한 사용자를 선별하는 것이다. |
| 확장 범위 | USB·파일 로그 연계는 추후 검토 대상이다. |


# 2. 추진 배경

## 실제 정보유출 사례

NIA 사례는 한 직원이 2022년부터 약 3년간 기관 이메일로 외부 업체 관계자에게 비공개 자료를 380회 전달한 사건이다. 반복적인 외부 전송이 장기간 탐지되지 않았다는 점이 이메일 행동 분석을 추진한 배경이다.

## 주제 선정 이유

- 평소와 다른 수신자, 전송량, 첨부파일 사용과 반복 전송을 분석하여 정보유출 징후를 조기에 찾기 위함이다.
- 제공된 이메일 로그에는 사용자, 발신자·수신자, 시간, 메일 크기, 첨부파일, BCC 정보가 포함되어 있어 사용자별 행동 분석에 적합한 구조이다.
