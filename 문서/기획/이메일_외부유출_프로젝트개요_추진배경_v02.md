# 1. 프로젝트 개요

## 프로젝트명

**SIEM 로그 기반 이메일 외부 유출 위험 사용자 탐지 및 위험 스코어링**

## 목표 및 범위

이메일 로그와 LDAP 정보를 활용하여 사용자별 평소 행동을 벗어난 외부 전송을 탐지하고, 위험점수와 조사 우선순위를 제공함.

| 구분 | 내용 |
|---|---|
| 목표 | 외부 전송 이상징후를 탐지하여 조사 대상의 우선순위를 제시함. |
| 분석 데이터 | 이메일 로그 및 LDAP 사용자 정보 |
| 분석 대상 | 외부 수신자, 전송량, 첨부파일, 메일 크기, BCC, 발송 시간, 반복 전송 |
| 분석 단위 | 사용자별·일별 이메일 활동 |
| 분석 방법 | 사용자별 평소 행동을 기준선으로 설정하여 이상 정도를 산출함. |
| 결과물 | 위험 사용자 순위, 위험점수, 점수 산정 근거 |
| 해석 범위 | 실제 정보유출자를 확정하지 않고 조사가 필요한 사용자를 선별함. |
| 확장 범위 | USB·파일 로그 연계는 추후 검토함. |


# 2. 추진 배경

## 실제 정보유출 사례

NIA 사례에서는 한 직원이 2022년부터 약 3년간 기관 이메일로 외부 업체 관계자에게 비공개 자료를 380회 전달함. 반복적인 외부 전송이 장기간 탐지되지 않았다는 점에서 이메일 행동 분석의 필요성을 확인함.

## 주제 선정 이유

- 평소와 다른 수신자, 전송량, 첨부파일 사용과 반복 전송을 분석하면 정보유출 징후를 조기에 찾을 수 있음.
- 제공된 이메일 로그에 사용자, 발신자·수신자, 시간, 메일 크기, 첨부파일, BCC 정보가 있어 사용자별 행동 분석이 가능함.
- 이메일 로그에 범위를 집중하여 전처리, 이상탐지, 위험점수 산정, 결과 제시까지 전체 분석 과정을 구현할 수 있음.
