# 1. NIA 사례 — 현재 데이터와 가장 직접적으로 연결됨

2025년 공개된 NIA 감사 관련 내용에 따르면, 직원 A씨가 **2022년부터 약 3년간 기관 이메일을 이용해 외부 민간업체 관계자에게 380회에 걸쳐 비공개 자료를 전달**한 것으로 확인됐습니다. 사업 심의 문서, 경영회의 자료, 평가위원 명단 등이 포함됐으며, 최초 유출 이후 약 3년이 지나서야 기관이 인지한 것으로 보도됐습니다.

- 관련 보도: [연합뉴스 — NIA 비공개 자료 외부 유출 관련 보도](https://www.yna.co.kr/view/AKR20250918058400017)

이 사례가 현재 데이터와 특히 잘 맞는 이유가 있습니다.

현재 `email.csv`에는 다음 컬럼이 존재합니다.

```text
date
user
pc
to
cc
bcc
from
size
attachments
content
```

따라서 사용자별 이메일 행동을 기준으로 다음과 같은 이상행동 지표를 만들 수 있습니다.

| 분석지표 | 현재 데이터로 가능 여부 | 의미 |
|---|---|---|
| 외부 이메일 활동 횟수 | 가능 | 사내 도메인 외 주소가 포함된 이메일 활동 횟수 |
| 외부 수신자 수 | 가능 | 외부 이메일 주소 개수 |
| 신규 외부 수신자 | 가능 | 최근 일정 기간 동안 없었던 새로운 외부 주소 등장 |
| 신규 외부 도메인 | 가능 | 과거에 없던 외부 이메일 도메인 등장 |
| 첨부파일 개수 | 가능 | `attachments` 컬럼 활용 |
| 이메일 크기 변화 | 가능 | `size` 컬럼 활용 |
| BCC 사용 증가 | 가능 | `bcc` 컬럼 활용 |
| 비정상 시간대 이메일 활동 | 가능 | `date`와 사용자별 평소 활동시간 비교 |

예를 들어 평소 이메일 행동이 다음과 같은 사용자가 있다고 가정할 수 있습니다.

```text
외부메일 평균      0.3회/일
첨부파일           0.2개/일
외부 수신자        기존 협력사 중심
주 활동시간        08:30~19:00
```

그런데 특정 날짜에 다음과 같은 행동이 발생한다면 평소와 다른 이상행동으로 볼 수 있습니다.

```text
외부메일          8회
첨부파일          11개
신규 외부 도메인 발생
23:40 이메일 활동 발생
```

이 경우 다음과 같은 흐름으로 분석할 수 있습니다.

```text
개별 이메일 행동지표 생성
        ↓
사용자별 평소 행동 Baseline 생성
        ↓
Z-score / Novelty 기반 이상도 계산
        ↓
복수 이상신호 가중 결합
        ↓
Email Risk Score
        ↓
위험 사용자 순위 및 산정 근거 제공
```

즉 NIA 사례에서 문제가 된 **장기간 반복적인 외부 이메일 자료 전달**이라는 행위 유형을, 현재 데이터에서는 사용자의 평소 이메일 행동과 비교하여 이상징후로 탐지하는 방향으로 연결할 수 있습니다.

## 분석 시 반드시 고려해야 할 한계

현재 `email.csv`에는 **발송·수신을 명시적으로 구분하는 `activity` 컬럼이 없습니다.**

또한 `user`와 `from`이 항상 같은 개념도 아닙니다. 따라서 외부 주소가 포함된 모든 이메일 이벤트를 곧바로 다음과 같이 해석하면 안 됩니다.

> “이 사용자가 외부로 자료를 전송했다.”

보다 보수적으로 분석하려면 LDAP에 등록된 사용자의 이메일 주소와 `email.csv`의 `from` 주소가 일치하는 이벤트를 **사용자가 발신한 것으로 추정되는 메일 후보**로 먼저 분리하는 방식이 적절합니다.

```text
email.from == 해당 user의 LDAP 등록 email
```

그다음 `to`, `cc`, `bcc`에 사내 도메인인 `dtaa.com` 외의 주소가 존재하는지를 확인하여 외부 이메일 활동 후보를 정의할 수 있습니다.

```text
to / cc / bcc에 dtaa.com 외 도메인 존재
        ↓
외부 이메일 활동 후보
```

따라서 현재 데이터로 탐지할 수 있는 것은 다음과 같이 표현하는 것이 가장 정확합니다.

> **“NIA 사건과 유사한 반복적인 외부 이메일 자료반출 징후”**

반대로 현재 데이터만으로 다음과 같이 단정할 수는 없습니다.

> **“실제로 이메일을 통해 비밀자료가 유출되었다.”**

즉 본 프로젝트에서는 실제 유출 여부를 확정하는 것이 아니라, **사용자별 이메일 행동 기준선을 바탕으로 평소와 다른 외부 이메일 활동을 탐지하고 위험점수로 우선순위화하는 것**이 핵심입니다.
