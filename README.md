# SIEM봤다

기업 보안 로그를 활용해 사용자의 정보유출·자산유출 이상행위를 탐지하고 위험도를 평가하는 프로젝트입니다.

## 디렉터리 구조

```text
문서/
├─ 관리/         # 저장소 운영 규칙, 라벨링 정책, 디자인 명세
├─ 기획/         # 프로젝트 및 MVP 기획 문서
├─ 분석/         # EDA, 분석 보고서, 위험지표 근거
├─ 자료조사/     # 데이터 사전, 사례 및 기술 조사
└─ 회의록/       # 회의록과 회의 녹취
코드/            # 재실행 가능한 분석·문서·프레젠테이션 생성 코드
산출물/
├─ 분석결과/     # 분석 결과 CSV·JSON
├─ 보고서/       # 배포용 PDF
├─ 프레젠테이션/ # 배포용 PPTX
└─ 검증/         # 산출물 검사·검증 결과
```

## 실행 방법

- 이메일 이상탐지 분석: `코드/이메일_이상탐지_분석.py`
- 통합기획서 PDF 생성: `코드/통합기획서_PDF_생성.py`
- 위험점수 프레젠테이션 생성: `코드/위험점수_프레젠테이션_생성.mjs`

각 스크립트의 로컬 데이터 및 도구 경로는 실행 환경에 맞게 확인해야 합니다.

## 데이터 관리

원본 데이터 폴더 `eda_security_data_clean_260915_01/`와 압축본 `eda_security_data_clean_260915_01.zip`은 용량과 보안상의 이유로 Git에서 제외합니다. 저장소에는 재현 가능한 코드, 문서, 요약 결과만 포함합니다.

## 저장소 관리 원칙

- 파일명은 내용을 식별할 수 있는 한글과 밑줄을 기본으로 사용합니다.
- 날짜가 필요한 파일은 `YYYYMMDD`, 버전이 필요한 파일은 `vNN` 형식을 사용합니다.
- 원본 데이터, 압축본, 임시 렌더링 파일과 의존성 폴더는 커밋하지 않습니다.
- 변경 이력은 복사본 대신 Git 커밋으로 관리합니다.
