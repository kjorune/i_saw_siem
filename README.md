# SIEM봤다

기업 보안 로그를 활용해 사용자·아이피·자산의 이상행동을 탐지하고 위험도를 평가하는 프로젝트입니다.

## 폴더 구조

```text
문서/
├─ 기획/       # 개발 기획, 착수 기획, 기업 자료 요청
├─ 관리/       # 팀 운영 및 저장소 관리 규칙
├─ 회의록/     # 회의 기록과 회의록 양식
└─ 자료조사/   # 논문, 용어, 기업·보안 사례 조사
```

분석 데이터와 코드가 추가되면 다음 기본 폴더를 사용합니다.

```text
데이터/
├─ 원본/
└─ 가공/
분석노트/
코드/
산출물/
```

빈 폴더는 미리 만들지 않습니다.

## 관리 원칙

- 팀이 작성하는 폴더와 파일 이름은 한글을 기본으로 합니다.
- `README.md`, `.gitignore` 등 도구가 요구하는 표준 파일명은 예외로 둡니다.
- 변경 이력은 파일 복사본이 아니라 Git 커밋으로 관리합니다.
- `최종`, `진짜최종`, `현행본`, `수정본` 등의 상태 표현은 파일명에 넣지 않습니다.
