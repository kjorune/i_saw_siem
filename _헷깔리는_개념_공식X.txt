* 헷깔리는 개념
 - 파싱과 정규화
 - 파싱: 원본 문자열에서 값을 분리해 필드로 뽑는 것
 - 정규화: 뽑힌 필드의 이름·형식·의미를 공통 규칙에 맞추는 것

* 용어 가장 쉬운 의미
정탐·TP	공격을 제대로 잡음
오탐·FP	정상인데 공격으로 잘못 잡음
미탐·FN	공격을 놓침
정상 판정·TN	정상을 정상으로 판단
정확도	전체 판단 중 맞힌 비율
정밀도	발생한 경보 중 진짜 공격의 비율
재현율	실제 공격 중 찾아낸 비율
오탐률	정상 행동 중 잘못 경보한 비율
미탐률	실제 공격 중 놓친 비율
특이도	정상 행동을 정상으로 알아본 비율
F1 점수	정밀도와 재현율의 균형 점수
Z-score	현재 값이 평소 평균에서 표준편차 몇 개만큼 떨어졌는지 나타냅니다.
임계값	몇 점부터 경보를 울릴지 정한 기준
기준선	사용자나 시스템의 평소 행동
이상행동	평소와 다른 행동
위험점수	사건의 위험 정도를 합산한 점수
신뢰도	시스템이 판단을 얼마나 확신하는지
상관분석	흩어진 로그를 하나의 행동 흐름으로 연결
라벨	공격·정상 여부를 나타내는 정답
클래스 불균형	정상 데이터가 공격 데이터보다 훨씬 많은 상태
ROC-AUC	공격과 정상을 구분하는 전체적인 능력
PR-AUC	불균형 데이터에서 정밀도와 재현율을 함께 본 점수
Precision@K	상위 K개 경보 중 실제 공격의 비율
탐지 지연시간	공격 발생 후 경보까지 걸린 시간


1. 가장 기본이 되는 4가지 결과
- 정탐(True Positive, TP) -> 공격도 맞고 경보도 울린것
실제 공격이 발생했고, 시스템도 경보를 울린 경우입니다.
- 오탐(False Positive, FP) -> 공격이 아닌데 경보가 울린것 -> 자원 소모 리스크
정상 행동인데 시스템이 공격으로 잘못 판단한 경우입니다.
- 미탐(False Negative, FN) -> 공격인데 경보가 안울린것 -> 미탐지 위험 발생
실제 공격인데 시스템이 경보를 울리지 않은 경우입니다.
- 정상 판정(True Negative, TN)
정상 행동이고 시스템도 정상으로 판단한 경우입니다
2. 주요 평가 지표
- 정확도(Accuracy)
전체 판단 중 시스템이 맞게 판단한 비율입니다.
정확도 = (정탐 + 정상 판정) ÷ 전체 건수
Accuracy = (TP + TN) ÷ (TP + FP + FN + TN)

- 정밀도(Precision)
시스템이 울린 경보 중 실제 공격이었던 비율입니다.
정밀도 = 정탐 ÷ (정탐 + 오탐)
Precision = TP ÷ (TP + FP)

- 재현율(Recall)
실제로 발생한 공격 중 시스템이 찾아낸 비율입니다.
재현율 = 정탐 ÷ (정탐 + 미탐)
Recall = TP ÷ (TP + FN)

- 오탐률(False Positive Rate, FPR)
전체 정상 행동 중 경보를 잘못 울린 비율입니다.
오탐률 = 오탐 ÷ (오탐 + 정상 판정)
FPR = FP ÷ (FP + TN)

3. Precision@K
위험점수가 높은 상위 K개 경보 중 실제 공격이 몇 개였는지를 나타냅니다.
4. 탐지 지연시간 - 공격이 발생한 시점부터 시스템이 경보를 발생시킨 시점까지 걸린 시간입니다.
5. 클래스 불균형 - 정상 데이터와 공격 데이터의 수가 크게 다른 상태입니다.
6. Z-score - 현재 값이 평소 평균에서 표준편차 몇 개만큼 떨어졌는지 나타냅니다. 

7. 이상행동과 위협의 차이
- 이상행동(Anomaly) - 평소와 다른 행동입니다.
- 위협(Threat) - 시스템이나 정보를 해칠 가능성이 있는 행동 또는 대상입니다.
